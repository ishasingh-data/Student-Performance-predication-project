## Project Overview

This project focuses on predicting **students' final exam scores using Machine Learning**. The model analyzes factors such as study hours, attendance, previous exam scores, parental education, internet access, and extracurricular activities to understand their impact on academic performance.

### Tools & Technologies

* Python
* Pandas & NumPy
* Scikit-learn
* XGBoost
* Matplotlib
* Machine Learning

### Key Features

* Cleaned and preprocessed student performance data
* Performed exploratory data analysis
* Encoded categorical variables and scaled numerical features
* Trained and compared Machine Learning models
* Used **XGBoost** for final score prediction
* Evaluated model performance using **MAE, RMSE, and R²**

### Objective

The main objective of this project is to demonstrate how Machine Learning can be applied to **analyze student-related factors and predict academic performance** using historical data.
